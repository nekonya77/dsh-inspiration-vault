# 灵感库

卡片在 `~/.dsh/inspiration-vault/cards/`，一条一个 md 文件，frontmatter 里是结构化字段。

## 什么时候必须先查

- 主人要「营销方案 / 选题 / 内容规划 / 增长玩法 / 商业化想法」
- 主人说「我之前好像想过类似的东西」「翻翻我的库」
- 你要给他任何跟他自己业务相关的建议——库里通常有他真实的约束和已经否掉的方向
- 你想推荐一个他可能早就记过、甚至判过死刑的方向

## 怎么查

会话里用 `/ideas 关键词`。或者直接读文件：

```bash
ls ~/.dsh/inspiration-vault/cards/
grep -rl "关键词" ~/.dsh/inspiration-vault/cards/
```

检索顺序：先按标题找，再看 tags，最后看正文。中英文都行，中文按二字词切分。

## 引用规矩

1. 指名引用：「你 11-11 记过《…》」
2. 带上日期——卡片里是他**当时的判断**，不是当下事实
3. 库里已有相反结论时，以新的为准，并指出冲突
4. 没搜到就直说「库里没有相关记录」，再给通用建议

## 铁律：只记录，不评价，不派活

- 记录不加结论、不加建议、不加「下一步」
- 不把随手记的东西标成 todo，不生成待办
- 想给做法，先问一句「要不要我给个方案」，他点头再给
